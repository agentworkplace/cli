# Contributing

Issues and pull requests are welcome. For a code change, include a focused test
when it helps demonstrate the behavior, and run `npm run verify` before opening
a pull request. A maintainer will review the proposal and explain its release
status. Accepted contributions are credited in the change or release notes.

By submitting a contribution, you agree that it may be distributed under this
repository's MIT license. Please report suspected vulnerabilities through the
private contact in [SECURITY.md](SECURITY.md), not a public issue.
